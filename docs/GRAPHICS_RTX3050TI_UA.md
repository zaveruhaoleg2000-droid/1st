# Графіка v0.0.23 для RTX 3050 Ti 4 ГБ

У native Vulkan додано текстури й освітлення матеріалів, реальні тіні та деталізовану 3D геометрію. Пакет Windows x64 включає Vulkan і CPU EXE. Цільовий профіль — висока якість для RTX 3050 Ti з 4 ГБ відеопам'яті; реальна швидкодія на цій карті ще не виміряна.

## Рендеринг

- 16 матеріалів із наявних ресурсів 512×512. Texture array містить десять mip-рівнів, сформованих із усередненням у лінійному просторі; sRGB sampling, trilinear та анізотропія до 8× за підтримки пристрою.
- Геометрія зберігається у device-local буферах; статичний кеш і передавання змінених діапазонів збережені. Докладні моделі бійців повторно використовуються між змінами симуляції/LOD/вибору. Staging текстур звільняється після завершення першого native кадру.
- Directional shadow map до 2048×2048, дев'ять PCF вибірок, slope bias; тіні від рельєфу, будинків, дерев, бійців та техніки. Одна shadow map має обмежену роздільність на великій території.
- Освітлення diffuse/GGX specular із приблизними параметрами шорсткості, текстурним рельєфом через похідні, sky ambient, мокрими та засніженими матеріалами. Це спрощена модель матеріалів без окремих художніх normal/roughness maps.
- MSAA до 4× з resolve у swapchain; екранне небо з градієнтом, хмарами та сонцем; атмосферний туман і filmic tone mapping.
- Вода має хвилі у вершинах, анімовані нормалі, Fresnel та аналітичне відбиття неба. Відбиття об'єктів через SSR або ray tracing не реалізовані.
- Колір сонця, неба й туману, вітер, мокрість і сніг надходять із чинної системи погоди. F2/F3/F4/F7/F8 керують часом, погодою, тінями, вітром і відбиттям води.

## Геометрія

- У близькому плані бійці використовують об'ємні корпус, голову, шолом, кінцівки, черевики, жилет, рюкзак та гвинтівку. Положення прив'язане до симуляції, напрямок — до наказу загону; є проста процедурна поза руху.
- До 650 м дистанції камери малюються окремі бійці; до 250 м — докладніші моделі. На дальньому плані залишаються маркери загонів.
- Декоративні танк, БТР та вантажівка мають корпуси, колеса/гусениці, башту або кабіну, зброю, скло й деталі. Водіння, пошкодження, фізика та AI техніки не додавалися.
- Будинки мають скатні дахи, вікна, двері й димарі; дерева — додаткові об'ємні частини крони в близькому плані. Розміщення будинків/дерев у річці обмежене.
- Основна сітка рельєфу 160×160, дальні кільця заповнюють горизонт без щільної сітки на всю територію. Зберігаються бюджети геометрії та LOD.

## Профілі пакета

| Запуск | Тіні | MSAA | Матеріали |
| --- | --- | --- | --- |
| PLAY_HIGH.bat / PLAY.bat | 2048px | до 4× | 512px, mip-рівні |
| PLAY_MEDIUM.bat | 1024px | до 4× | 512px, mip-рівні |
| PLAY_LOW.bat | 512px | вимкнено | 512px, mip-рівні |
| PLAY_CPU.bat | попередній CPU-рендерер | CPU AA | попередні CPU матеріали |

Профіль задається до запуску. MSAA використовується лише за підтримки пристрою. За відсутності системного Vulkan loader `PLAY.bat` запускає окремий CPU EXE; при помилці ініціалізації чи present Vulkan EXE переходить на CPU.

## Перевірки

- Linux CPU Release та Debug: по 25/25 тестів. Vulkan Release: 26/26 із Khronos synchronization validation на Mesa Lavapipe.
- Native інтеграційний тест читає реальні X11 pixels, порівнює переміщення підрозділів, тіні ON/OFF, дощ/сніг і хвилі води; перевіряє resize та відсутність повторного mesh upload. Також перевірено низький профіль.
- Контрольний кадр: 16 текстур, тіні 2048px, MSAA 4×. Renderer-owned allocations під час галереї 1280×720 — близько 103 МіБ, включно з host staging геометрії; це не повне споживання процесу чи VRAM драйвера/swapchain.
- Windows x64 CPU/Vulkan Release: по 23/23 тестів під Wine. Обидва EXE проходять CPU запуск із повністю запакованими ресурсами.
- Windows `--gpu-smoke-test` під Wine/Mesa подав шість native кадрів: 16 текстур, тіні 2048px, MSAA 4×, без CPU fallback. Це перевірка Win32 Vulkan шляху через Wine, а не Windows 11 чи фізична GPU.
- У Linux validation errors = 0. У Wine запуск із `GZ_VULKAN_VALIDATION=1` не зміг створити instance; native Windows перевірка пройшла з вимкненими validation layers. Значення лічильника 0 у такому запуску не підтверджує Windows validation.

## Відомі межі

Фізична RTX 3050 Ti та Windows 11 тут недоступні. 1080p/60 FPS не виміряні. Моделі процедурні й стилізовані, без готових професійних 3D assets; native GPU HUD і частина CPU battlefield effects ще не мають повної відповідності. CPU fallback зберігає попередній вигляд і логіку гри. Ray tracing, SSR, SSAO та нова фізика техніки не впроваджені.

## Збірка й перевірка пакета

```sh
cmake -S . -B build-vulkan -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DGZ_ENABLE_VULKAN=ON -DGZ_REQUIRE_VULKAN=ON -DGZ_VULKAN_RUNTIME_TESTS=ON
cmake --build build-vulkan --parallel 2
ctest --test-dir build-vulkan --output-on-failure
```

У Windows: `build_windows.bat`, а CPU — `build_windows_cpu.bat`. Портативний пакувальник:

```sh
python scripts/package_windows_portable.py --cpu-build build-win-cpu --vulkan-build build-win-vulkan --dist dist-win-graphics --zip GRAY_ZONE_1989_RTX3050TI_WIN_X64.zip
```

У Windows пакувальник також запускає CPU smoke; у Linux передайте `--smoke-runner /path/to/wine-wrapper` та запустіть його під Xvfb. `--verify-native` вимагає робочого Vulkan-драйвера й відхиляє fallback. Під час тестування сформовано справжні native screenshots 1280×720; вони не є концепт-артом.
