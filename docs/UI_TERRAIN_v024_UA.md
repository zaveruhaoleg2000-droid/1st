# v0.0.24 — інтерфейс, генерація рельєфу й макротекстури

Реалізовано native Vulkan HUD: українські написи, кнопки паузи/режиму/ходу/утримання/мапи/якості, картки загонів із чисельністю, боєприпасами та індикатором здоров'я, мінікарта, маркери вибору й наказу. Інтерфейс малюється окремим alpha-blended GPU pass; повний CPU кадр для цього не растеризується. CPU fallback зберігає попередній інтерфейс.

Вибір юнітів і наказ у точку використовують актуальну native камеру та перетин променя з рельєфом. Старий CPU picking перед використанням оновлює власну камеру. Хід кнопкою й Enter виконує 50 тиків, тобто 5 секунд ігрового часу.

Нові кампанії мають seed і версію генератора. Для Варшавського коридору використано профіль полів, для Прип'яті — заболоченої долини, для Дунаю — лісистих пагорбів. Генератор зберігає безперервні краї heightmap, формує пагорби, русло/береги й дорожні ухили. Карти висот готуються одним фоновим завданням на TerrainWorld і кешуються на диску. До завершення карти відтворюються ті самі квантовані семпли, тож геометрія не змінюється при її появі.

Campaign save v3 містить seed/version/region. Читач зберігає підтримку v1/v2; старі кампанії й окремі legacy simulation saves використовують початковий рельєф із наявних assets. Перевірено міграцію v2→новий читач та v3 round trip; simulation save format не змінювався.

Макротекстура активної ділянки світу покриває 8192×8192 м, поєднується з наявними detail матеріалами й має повний sRGB mip chain. Профілі: high 4096px, medium 2048px, low 1024px. Це одна рухома world-aligned ділянка з узгодженим кроком, а не дев'ять постійно резидентних 4096px текстур. Поза краєм ділянки shader плавно переходить до detail матеріалів.

Низькочастотні колір/біоми обчислюються на обмеженій сітці 256×256; дорожні маски та світова варіація зберігають повну роздільність вихідного зображення. Генерація проходить у фоні, без перепобудови всієї геометрії при появі текстури. Нові окремі художні normal/roughness maps ще не додані; використано попереднє освітлення й texture derivatives.

Перевірено Linux CPU Debug/Release по 27 тестів, Vulkan 28 тестів із synchronization validation; Windows CPU/Vulkan по 25 тестів під Wine. Windows native package smoke перевіряє >=6 кадрів, HUD uploads, macro 4096px, 16 матеріалів, shadow map 2048px і MSAA 4x. Wine запускається без validation layers; Linux native галерея перевірена з ними. Фізична RTX 3050 Ti та Windows 11 тут недоступні, FPS не виміряні.

Огляд зі справжніми кадрами: [REVIEW_v024_UA.md](REVIEW_v024_UA.md). Знімки тактичної сцени отримані з native Vulkan window через Mesa Lavapipe; меню та стратегічна карта — із CPU runtime під Wine.

Не додавалися navigation/collision, бойова AI техніки, справжні укриття, нові типи контрактів або окрема генерація поселень. Native mesh ще перебудовує статичну геометрію при зміні фокусу; повний chunk streaming залишається наступним етапом. Нова UI quality кнопка працює для GPU; повне меню графічних налаштувань і незалежний масштаб UI ще потребують роботи.
