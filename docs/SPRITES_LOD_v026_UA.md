# v0.0.26 — спрайти, прозорість, ефекти та 4 рівні LOD

Ідея поєднати командну стратегію з керуванням окремим бійцем сильна: результати власних наказів можна побачити з поля бою. Для RTX 3050 Ti 4 GB доречний гібрид об’ємних моделей і спрайтів. Він дає насиченіше оточення при обмеженій геометрії. Прозорі площини також створюють навантаження на пікселі, тому щільність, дальність трави й загальну кількість ефектів обмежено.

## Що працює

- Окремий native SpriteBatch: RGBA, alpha cutoff для рослинності, змішування для диму/хмар/ефектів, depth test без запису depth, сортування від далеких карток до близьких.
- 16 процедурних шарів 256×256: дерева, сухі гілки, трава, очерет, квіти, папороть, хмара, спалах, дим, іскра/трасер, пил, влучання, дощ, крона, вогонь. Частина шарів — запас каталогу; папороть/дощ/вогонь не мають окремих автоматичних emitter систем у цій версії.
- Ближні дерева: об’ємний стовбур і картки крони. Далі — повний billboard дерева. Трава й хмари малюються спрайтами. Рослинність отримує alpha-tested directional shadows у Vulkan. CPU fallback також малює спрайти, із простішими тінями.
- Ефекти ручного й автоматичного вогню: спалах біля ствола, дим, короткий трасер, пил/влучання та іскри. До 128 недавніх подій пострілів; їхній час прив’язано до симуляції, тому пауза їх зупиняє.
- Ліміт 4096 карток на кадр, трави/рослинності до 2800, дальність трави 40/65/90 м за якістю. GPU upload спрайтів обмежено 4 MiB на кадр. Зміни вітру впливають на їхню анімацію.
- 39 базових матеріалів із normal maps замість 31. Додано уламки, мох, стебла очерету, квіти, соснову кору, штукатурку, іржу та плитку.
- Каталог оточення розширено з 16 до 32 моделей: намет, антена, електроопора, уламки, джип, лавка, мішки, контейнер, спостережна вежа, пошкоджена стіна, гідрант, колодязь, пам’ятний хрест, знак, бар’єр, палета та попередні об’єкти. Техніка залишається декоративною.

## Чотири рівні моделей

| LOD | Базова дистанція | Зміст |
| --- | --- | --- |
| 0 — ближній | до 40 м | Максимальні деталі, спорядження, зброя, колеса/оптика |
| 1 — середній | 40–120 м | Менше сегментів, дрібні деталі прибрано |
| 2 — дальній | 120–320 м | Прості частини, дешевша геометрія й зброя |
| 3 — силует | від 320 м | Основні об’єми або командні маркери; дерева billboards |

Великі об’єкти використовують масштабовані пороги: техніка ×2, будівлі ×4. Для бійців відстань визначається від камери, із гістерезисом 12%, щоб деталі не перемикалися постійно на межі. Статичне оточення оновлює деталізацію при зміні дистанційної смуги камери. Прості props вже мають мало полігонів і не всі потребують чотирьох різних сіток. Каталог зброї має чотири геометричні варіанти на тип; FPS використовує ближній.

## Бюджети та ресурси

- 39 матеріалів із normal maps на диску: 47,92 МБ; RGBA sprite atlas: 4,19 МБ.
- Розрахований максимальний резидентний текстурний payload із mip-рівнями, macro 2048 і шрифтом: **98,15 МБ із 100 МБ**. Depth/MSAA/shadow targets, staging, геометрія та пам’ять драйвера рахуються окремо.
- 5 типів зброї з LOD каталогом: **0,427 МБ із 50 МБ**.
- 32 baked моделі оточення: **1,016 МБ із 200 МБ**. Heightmaps/Europe assets і активна геометрія додаткові; повний каталог не збільшується штучним заповненням до ліміту.
- Генератори відтворюються за seed 1989. Sprite atlas: `python3 scripts/generate_sprite_atlas.py`; матеріали: `scripts/generate_procedural_textures.py`; моделі: target `grayzone_procedural_assets`.

Нові варіанти не змінюють campaign або simulation save format після v025. Здоров’я/броня, зброя, керування FPS і реальний час із паузою зберігаються. Докладне керування: [GAMEPLAY_v025_UA.md](GAMEPLAY_v025_UA.md).

## Перевірка й оцінка

Linux Vulkan: 30/30 тестів із synchronization validation; CPU Debug/Release: по 29/29; Windows CPU/Vulkan під Wine: по 27/27. Native gallery містить реальні кадри зі спрайтами, HUD, foliage та пострілом. Реальні XTest події на Linux підтвердили рух/огляд, витрату патронів, паузу, перезарядку, пістолет, зміну бійця й повернення в тактику. Додатковий XTest сценарій під Wine не зміг знайти вікно; це не зараховується як пройдена перевірка Windows input. Упакований Windows native smoke окремо перевіряє спрайти, ручний постріл, FPS mesh/HUD і відсутність CPU fallback.

Це робочий стилізований процедурний прототип. FPS на фізичній RTX 3050 Ti/Windows 11 ще не виміряний. Спрайти не замінюють колізії й укриття; стіни поки не блокують рух/постріли, техніка не керована. Наступний найцінніший етап — collision/navigation і LOS/укриття, а потім різні шаблони місій та інтерактивна машина. Це дасть більше глибини, ніж подальше зростання кількості assets.
