# GRAY ZONE: 1989 — бібліотека матеріалів v0.0.8

Створено **16 оригінальних процедурних безшовних (tileable) матеріалів**, без сторонніх текстур і залежності від мережі. Підготовлено фактичні PNG-файли, придатні для інших рушіїв, а також компактний власний GZT1 для поточного CPU-рендерера.

## Структура

```
assets/textures/
  CONTACT_SHEET.png             # візуальна таблиця всіх 16 матеріалів
  manifest.json                 # ID, масштаб, рівні деталізації, призначення
  grass_short/
     grass_short_128.png         # albedo / base color
     grass_short_256.png
     grass_short_512.png
     grass_short_1024.png
     grass_short_normal_256.png  # tangent-space RGB normal map
     grass_short_normal_512.png
     grass_short_roughness_256.png  # L8 roughness
     grass_short_roughness_512.png
  ... /                          # аналогічно для кожного матеріалу
  runtime/
     grass_short_128.gzt        # GZT1 для CPU-рушія
     grass_short_256.gzt
     grass_short_512.gzt
     ...
```

## Матеріали

| Група | ID |
|---|---|
| Рослинність | `grass_short`, `grass_tall`, `meadow`, `leaves`, `tree_bark` |
| Ґрунти | `dirt_dry`, `mud_wet`, `sand`, `gravel`, `rock`, `snow` |
| Інфраструктура | `asphalt`, `concrete`, `brick`, `wood_planks` |
| Водойми | `water` |

Фактичні PNG albedo **128, 256, 512, 1024 px**; normal+roughness **256 і 512 px**; GZT1 runtime **128, 256, 512 px**.

## Підключення до поточного рендерера

```cpp
gz::Renderer renderer;
renderer.resize(960, 600);
renderer.loadTextures("assets/textures/runtime", 256); // 128 low / 256 default / 512 high
renderer.setTexturing(true); // false => старий однотонний рендер
```

`Renderer::drawTerrain()` використовує UV із світових метрів, відбір матеріалу за типом ділянки (луг, трава, ґрунт, гравійна дорога, схили), а `drawProps()` — текстури цегли, дощок, кори та листя. Вода зберігає процедурні хвилі/відображення та змішується з `water`. Для плоских і вертикальних трикутників використовується простий вибір осі UV за нормаллю поверхні. У глобальному режимі є окрема карта, яка цю бібліотеку поки не використовує.

Поточний CPU-рендерер **поки НЕ застосовує** normal/roughness у фізичному освітленні — вони лежать у каталозі як підготовка до GPU матеріалів. Так само немає автоматичної зміни міпів під час руху камери: одночасно завантажується одна вибрана роздільність кожного матеріалу. Немає готового Direct3D11.

Формат `.gzt`: 4 ASCII байти `GZT1`, uint16 little-endian ширина, uint16 little-endian висота, далі щільні RGB8 пікселі в рядковому порядку. Імена й UV масштаб зазначені у `manifest.json`.

Орієнтовна пам'ять усіх матеріалів, якщо завантажити одночасно: **1 MiB при 128**, **4 MiB при 256**, **16 MiB при 512** (RGBA32 у CPU-пам'яті). Це вимірює тільки колірні текстури, без кадрового буфера, геометрії, кешу мап та системних витрат.

## Підтримка безшовності

Генератор використовує періодичні шуми й робить крайні стовпці та рядки кожного рівня ідентичними. Це запобігає помітній лінії на стику тайлів, хоча не забезпечує ідеальне mip-фільтрування. Повторення UV також працює для від'ємних координат.

## Відтворення матеріалів

```
python tools/generate_textures.py --output assets/textures
```

Вимоги до генератора: Python 3, numpy, Pillow. Для **запуску гри** Python не потрібен. Всі вихідні зображення вже входять до пакета. Версія генератора відтворювана: фіксований seed для кожного матеріалу.

## Важливе обмеження продуктивності

Це ранній одноядерний програмний растеризатор, і текстурний семплінг збільшує витрати CPU. Гра наразі **не гарантує 60 FPS** на цільових 4 потоках. Текстури структуровано для наступної оптимізації / переносу на GPU. Задекларовані раніше 4GB RAM, 2GB VRAM, 1GB на диску — цільові обмеження, а не результат профілювання готової гри.
