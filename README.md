GRAY ZONE: 1989 v0.0.25 — tested Windows x64 prototype

Повністю розпакуйте ZIP, запустіть PLAY_HIGH.bat. CPU fallback: PLAY_CPU.bat.
Клавіші: 1 тактика, 2 перша особа, 3 мапа, Space пауза. FPS: WASD/миша,
ЛКМ вогонь, ПКМ приціл, R перезарядка, F пістолет/основна, Tab боєць.
Покроковий режим видалений; HUD і шрифт оновлені. Ручна стрільба, броня,
процедурна зброя/оточення/текстури та супутниковий стиль карти.

Готові EXE пройшли CPU/native Vulkan запуск із пакета під Wine, включно
з ручним пострілом і FPS HUD. Фізична RTX 3050 Ti та Windows 11 тут недоступні.

Документація: GAMEPLAY_v025_UA.md. Зображення previews — справжні кадри рушія.
Техніка декоративна, колізій стін і блокування вогню будівлями ще немає.
